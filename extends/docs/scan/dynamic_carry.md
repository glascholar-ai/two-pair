# 动态 cash-and-carry：perp 溢价 + funding 联动择时（vs 静态持有）

**日期**：2026-08-21
**脚本**：`extends/scan_dyncarry.py`
**数据**：Binance `premiumIndexKlines` 5m（perp 对指数溢价；KRX 开盘时段指数=供应商
定价的真实底层，故此时溢价=可交易基差），2026-06-02（上市）→ 08-21，SKHYNIX/
SAMSUNG；funding 全历史来自 perpfund 追踪库（`~/app/stocka/data/perpfund.db`，
BN 159 名字 + HL 94 名字）。周期明细 `dyncarry_cycles.csv`。
**动机**：skfunding 实盘（07-29 建仓 → 08-21 清仓，$5.3M 名义，费后 +$187k =
funding $164k + 进出场基差 $27.5k；进场 perp 溢价 +77bp、出场 −19bp）。命题：
"溢价高（往往也是 funding 高）时进、基差消失/funding 转负时出"的动态规则是否
优于静态一直持有——约束是韩股每个周期 ~25–43 bps 的往返摩擦（卖出税+佣金+perp 费）。

## 结论速览

1. **命题成立（KR 两名字、80 天样本）**。SKHYNIX：静态持有净 1177 bps；动态
   （1h 均溢价 ≥30 bps 进、≤−10 出）净 **1653 bps（低摩擦 25bps/周期）/
   1203（高摩擦 43bps）**，25 个周期、在场 86%。SAMSUNG：静态 714，动态最好格
   1166/662。**动态在低摩擦口径下比静态多 40–60%，高摩擦口径下与静态打平或略胜**
   ——且少担 14–20% 的在场时间。
2. **超额从哪来（SKHYNIX 30/−10 格）**：反复卖高溢价的基差和 +836 bps（静态只有
   进出各一次 = +21）；funding 和 1442 vs 静态 1181——**差额 ~260 bps 就是躲开的
   负 funding 时段**，与"funding 转负时退出"的直觉一致。
3. **但不要用 funding 本身做出场信号**：显式"尾 3 日 funding ≤0 即出"使周期数
   从 ~25 涨到 57–180，摩擦吃掉全部超额（SAMSUNG 直接 −2600 bps）。**溢价领先
   funding**（BN funding 本来就是溢价的钳位滑动平均：当日 corr 0.42–0.47，溢价
   对次日 funding 的领先相关 > 反向），溢价出场已经隐含了 funding 择时，且更早。
4. **funding 高位有持续性，"盯板子"成立**：SKHYNIX 尾 7d >40% APR 时，未来 7d
   中位仍 48% APR（n=49）；SAMSUNG >40% → 未来 27%（部分回落）。横截面（BN 全部
   名字，尾 7d 排名 vs 未来 7d 排名）近三个月 Spearman 0.26–0.50 恒正。30d 榜：
   BNC 74% / SKHYNIX 43% / ZHIPU 29% / SAMSUNG 26% / HK0700 22% APR。
5. **月度稳健性（30/0 格）**：SKHYNIX 三个月净皆正（+599/+770/+144 bps），但
   8 月明显收窄（溢价 regime 在压缩，8 月 funding 也只有 123 bps/21 天 ≈ 21%
   APR）；SAMSUNG 的超额六成来自 6 月上市初期（+731），8 月 ≈ 0。**上市初期
   溢价大、衰减快，这个策略的黄金期是新名字上市后的头两个月**——8/21 清仓
   离场的时机选择事后看是对的。
6. 与 08-18 报告《hl_kr_spread_mr.md》不矛盾：那份否决的是 **BN vs HL 两条 perp
   腿之间 ±20 bps 尺度的对称 fade**（费后无肉）；本文验证的是 **perp vs 真实底层
   的 30–300 bps 溢价 + 40–70% APR funding 的同向收割**——后者正是前者最差亏损
   交易的对手方向。两份报告共同指向同一结构：**偏离在给 funding 定价，站在收
   funding 的一侧才有生意**。

## 2. 回测口径

- 决策只发生在 KRX 开盘棒（工作日 00:00–06:20 UTC，剔除 6/3、7/17、8/17 假日
  ——假日指数冻结/EWMA 模式，溢价读数不是可交易基差，股票腿也无法成交；此修正
  把 SAMSUNG 的表观超额砍掉约 1/3，**不剔假日会显著高估**）。
- 进：1h 滚动均溢价 ≥ E；出：≤ X；成交按当棒 5m 溢价值计。PnL = (溢价_进 −
  溢价_出) + 持仓期 funding 和（4h 一期，来自 db）− 每周期摩擦。
- 摩擦两档：25 bps（股票 佣金~4+卖出税~20 + perp maker 0）/ 43 bps（+perp taker
  8 + 保守税费）。**未建模**：股票腿融资利息（KRW 借款 ~3.5%/年 ≈ 在场 70 天
  ~67 bps，静态/动态几乎同减，不改变相对结论但压低两者绝对值）、盘口滑点、
  perp 腿保证金占用的机会成本。

## 4. 对"综合监控程序"的具体建议

perpfund 已覆盖 funding 侧（双所、小时级同步、横截面榜）。缺的只有溢价侧：

1. 给 perpfund 加一个 `premiumIndexKlines` 同步（BN 侧现成 5m 端点，KR/HK 名字
   优先）+ 一个"KRX/港股开盘时段均溢价"列，与 funding APR 并排；
2. 告警规则即本文进出场：**开盘时段 1h 均溢价 ≥30 bps 且尾 7d funding APR ≥30%
   → 进场候选；≤−10 bps → 离场候选**。溢价是领先指标，funding 是确认指标；
3. 横截面持续性（Spearman 0.3–0.5）意味着新名字上市初期的高溢价+高 funding
   组合值得系统性扫描（本轮 BNC 74% APR、ZHIPU 29% 都属此类）；但每个新名字要
   过 skfunding 同款尽调（可借券性/母市场流动性/税费/PM 保证金）。

## 5. 局限

单一 regime（KR 名字上市后的头 80 天，溢价单调压缩期）；两个名字非独立（同市场
同方向）；决策与成交同棒（5m premium index 是指数级数据，无盘口滑点）；股票腿
融资与借券成本未入模；8 月的超额已明显变薄——**规则本身（溢价进出）比历史收益
数字更可信**。
