# 动态 funding 套利组合回测：BN/HL 全股票 perp 域，$10M，过去一个月

**日期**：2026-08-21
**脚本**：`extends/scan_dyn_select.py`（选域）→ `scan_dyn_fetch_bn.py`（BN aggTrades
批量→1s bar）/ `scan_dyn_fetch_hl.py`（HL 5m/15m K 线）/ `scan_dyn_fetch_ib.py`
（IBKR 正股 1m + 头部 10s + FX，映射经指数价校验）→ `scan_dyn_backtest.py`（组合模拟）。
**窗口**：2026-07-22 → 08-21（30 天）。**明细**：`docs/scan/dyn_positions.csv`。
**规格**（用户设定）：资金 $10M = $5M 股票现金腿 + $5M perp 保证金（1×名义）；
排除 SKHYNIX 与 pre-IPO（ANTHROPIC/OPENAI；ZHIPU/MINIMAX 等港股保留）；单名字
仓位 ≤ 15% × 该 venue 当时 OI（BN 用小时级 OI 历史，HL 用快照）且 ≤$1.5M。

## 结论速览

1. **组合净收益 ≈ $176k/30 天 ≈ 21.5% 年化（$10M 口径）**：A 类（perp vs 正股
   carry，53 笔）$134k + B 类（BN-HL 双 perp funding 差，15 笔）$42k。保守口径
   （剔除所有持仓 <6h 的短单——执行假设最脆弱的一档）$150k ≈ 18%；只认 funding、
   基差捕获全部归零的下限口径 ≈ $100k ≈ 12% 年化。
2. **本次最重要的产出是回测假象的定价**：同一策略、同一数据，首跑报 $9.2M/月
   （1125% 年化）。四轮修正——①决策/成交改 1h 滚动中位（杀盘口弹跳）→ $864k；
   ②往返成本加 2×实测有效半价差（杀 HL 薄名字价差收割）→ $421k；③HL 腿只认
   同 5m 窗口且 ≥3 笔成交的新鲜价（杀 asof 陈旧价套利）→ $187k；④时段内分块
   平滑（杀开盘/隔夜断口幻影）→ $176k。**98% 的表观利润是微观结构假象**；最终
   数字对进一步收紧已不敏感（③→④仅 −6%），可信度以此为界。
3. **收益结构**：A 类 $162k 基差 + $58k funding − 成本；basis:funding ≈ 3:1，
   但基差捕获集中于少数事件单（SAMSUNG 假日重开、NBIS/LITE 盘中错位），funding
   是更可复现的底仓。B 类几乎纯 funding（$87k funding，基差与成本抵消后净 $42k）。
   胜率 94%（53 笔 A 中 3 笔亏）——这是收割型策略的典型形态，**30 天窗口没有采样
   到尾部**（HL oracle 事故、不收敛的错位），高胜率不代表低风险。
4. **容量卡在 $5M 满负荷**：股票腿几乎每天用满（日均 11–13 个并发仓位），说明
   在当前阈值下机会多于资金——扩资金或提名字上限（现 $1.5M）都能线性加一段，
   直到吃满各名字 15% OI 槽位（候选域总槽位约 $40M）。B 类**未计入** $10M：
   按用户风险规则 **perp 侧杠杆 ≤1×**，B 双腿需等额保证金（峰值名义 $16.7M →
   需 $16.7M 资金），必须砍到头部两三名才装得进合理资金盘子。
   **【修正 08-21，用户纠正后】1× 约束下 A/B 排序反转**：每 $1 名义 A 与 B 同占
   $2 资金（A：$1 股票现金 + $1 perp 保证金；B：两腿保证金各 $1），而 A 的
   funding 严格更多（AVGO：A 空 HL 收 44.6% vs B 还要付 BN 腿 2.9%）——正
   funding、正股可达的名字应用 A 做；B 只保留给 (a) 负 funding 名字（A 需
   融券空正股，新 IPO 借券贵且不稳，如 CBRS）、(b) 正股不可达/税费重的名字
   （CXMT 型、港韩小差价）、(c) 正股闭市时段的战术进出。A/B 本质是同一策略
   "空贵 perp"配不同对冲腿：正股（funding 让渡最少但吃现金/税费/时段/借券）
   vs 对面 perp（让渡一点 funding 换可达性）——逐名选最优对冲腿，而非两个
   独立策略。
5. **头部贡献**：SAMSUNG 双线 $48k（与 `dynamic_carry.md` 溢价+funding 择时结论
   一致，KR 名字仍是单名字最厚的）；AVGO B 类 $24k（HL 44.6% APR vs BN 2.9%）；
   CBRS B 类 $16k；LITE/NBIS/MU 盘中错位单合计 $27k（可信度最低的一档）；
   BNC/BOT/AXTI/APP/TENCENT 等 funding 长持仓合计 ~$25k。

## 1. 设计

- **域**：BN 170 个 TradFi perp（exchangeInfo underlyingType 分类，PREMARKET 剔除）
  ∪ HL xyz/para 股票 dex；30d |funding APR| ≥8% 或 BN-HL 差 ≥15% 进入候选；
  71 个 A 类候选（57 个通过 IBKR 映射+指数价校验）、11 个 B 类。
- **A 类信号**：溢价 = ln(perp/正股)（bps，正股经 IBKR 实时 FX 折 USD），只在
  正股主盘时段决策（美 13:30–20:00 / 港 1:30–8:00 / 韩 0:00–6:20 / 日 0:00–6:30
  UTC，剔各自假日）；1h 滚动中位（时段内分块）≥ max(1.5×往返成本, 20bps) 且
  尾 7d funding APR 同向 ≥8% → 下一 bar 进场；中位 ≤0 → 出场；出场后 2h 冷却。
  方向：溢价+高 funding → 空 perp 多正股；折价+负 funding → 反向（收 1% 借券费）。
- **B 类信号**：尾 7d funding APR 差（BN−HL）|·| ≥15% APR 进、≤5% 出，6h 决策格。
- **成本**：股票腿往返 美 6 / 港 26 / 韩 24 bps + perp 腿 BN taker 8 / xyz 1.8 /
  para 9 bps + **2× 实测有效半价差**（该名字 5m 收盘对数变化中位数，下限 1bp）；
  funding 按 perpfund.db 实际事件序列逐笔累计（BN 美股 8h/韩股 4h、HL 每小时）。
- **执行假设**：成交价 = 下一 5m bar 的 1h 中位溢价（不是最优价也不是最差价）；
  HL 腿只在该 5m 窗口有 ≥3 笔成交时才认为有价。

## 4. 风险与局限

- **尾部未采样**：30 天无 HL oracle 事故（7/27 SKHX −17.9% 在窗口外）、无不收敛
  错位、无 funding 单期极端值击穿。94% 胜率会在尾部事件里一次性回吐数月收益——
  HL 腿仓位应设单名字损失上限，且 HL 侧保证金按 mark 独立漂移 ≥3% 预留。
- **执行假设中性但未验证**：1h 中位价成交在慢镜头（funding 长持仓）里合理，在
  快镜头（LITE/NBIS 这类 2h 错位单）里偏乐观——这 $27k 打对折看待。
- **费率促销依赖**：BN maker 0/taker 4bp、HL growth-mode 随时可回调；HL taker
  恢复 9bp 会把 xyz 腿成本抬 ~14bp/往返，B 类头部仍活着，A 类阈值需上调。
- **funding 持续性风险**：30d APR 榜是回望的；`dynamic_carry.md` 已证横截面
  持续性 Spearman 0.26–0.50（周度），但单名字会衰减（SKHYNIX 自身即例）。
  实盘必须按周重选域，而非持有静态名单。
- 股票腿融资/机会成本未入模（现金买股无杠杆则无利息，但占用 $5M 的无风险收益
  ~4% APR 应从年化里心算扣除）；KR 卖出税按 20bp 计于韩股往返成本。

## 5. 裁决与下一步

**值得做**，但形态与直觉不同：这不是"一套 $10M 一直跑"的静态机器，而是
**每周重选域的收割组合**——底仓是 funding 长持仓（B 类头部 + A 类 BNC/AXTI/
TENCENT 型），机会仓是 KR/HK 名字的溢价周期（SAMSUNG 型，`dynamic_carry.md`
的规则），短错位单可选（执行最难、可信度最低）。合理预期 **12–18% 年化**
（保守口径），上限受 OI 槽位与促销费率约束。

下一步（按性价比；对冲腿按 §结论4 修正逐名选择，perp 杠杆一律 ≤1×）：
1. perpfund 加"溢价列 + 进出场告警"（`dynamic_carry.md` §4 规格），先纸面跑
   两周验证 1h 中位价的可成交性;
2. 最先实盘的小规模组合：正 funding+正股可达的用 A（AVGO 型、SAMSUNG/ZHIPU/
   MINIMAX——母市场流动性好、funding 厚，正股腿走 skfunding 同款 IBKR 通道）；
   负 funding/借券难的用 B（CBRS/SHAZ 型，纯 perp、无股票腿）;
3. 短错位单（LITE/NBIS 型）暂不做——执行假设最脆弱、贡献占比可控。
