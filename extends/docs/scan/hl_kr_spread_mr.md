# Binance vs Hyperliquid 韩股 perp 跨所价差均值回归：成交级回测

**日期**：2026-08-18
**脚本**：`extends/scan_hl_krspread.py`（数据刷新用 `scan_hl_fetch.py SKHX SMSN SKHY`）
**数据**：5m 对齐棒 2026-07-28 18:45 → 2026-08-18 09:25 UTC（20.6 天，含 8/15–8/17
韩国光复节三连休与 8/18 KRX 重开）；SKHX/SKHYNIX 5934 棒、SMSN/SAMSUNG 5864、
SKHY/SKHY（美 ADS 线，对照）5946。逐笔明细 `hl_krspread_trades.csv` /
`hl_krspread_trades_filtered.csv`。
**背景**：`binance_vs_hl.md`（08-15）已裁决美股名字无空间、韩股腿是唯一有 3 倍噪声
的档但只做了棒级统计。本文回答"fade 韩股跨所价差扩大"是否成一笔可交易的生意。

## 结论速览

1. **回归现象本身：真。** dev（价差 − 24h 滚动中位锚）越过 20 bps 后 100% 在 24h 内
   收敛回 5 bps 内（0 笔超时），中位收敛 1–1.5h；毛利中位 +13.6 bps（SKHX thr=20）。
   观察者看到的"平时 ~$1（≈10 bps），偶尔拉大到 $2–5（20–50 bps）再收敛"与数据一致
   （|spread| 中位 10 bps，p99 42–47 bps，SKHX ≈ $1080）。
2. **但裸 fade 是亏的，主因是资金费污染，不是费率。** Binance 韩股 perp 资金费为
   **4h 一期**（00/04/08/12/16/20 UTC；美股名字才是 8h——修正 `binance_vs_hl.md` 的
   笼统说法），单期 |rate| p99 22–31 bps、极值 50 bps。价差偏离经常是在**给即将结算的
   资金费定价**（BN 相对便宜 30 bps ≈ 多头 1h 后要付的 50 bps 费），fade 它 = 站到支付
   侧：未过滤时资金费平均 -3.7~-6.1 bps/笔，最差单笔 -47 bps 全部来自资金费。
3. **资金费感知过滤 + BN maker 执行后，SKHX 有一个统计显著但经济上很小的边**：
   thr=20 过滤后 17 笔 / 20.6 天，BN-maker 口径 +10.4 bps/笔（t=3.85，胜率 taker 口径
   65%），双 taker 口径只有 +2.4 bps/笔（t=0.9，不显著）。SMSN 更弱（maker +4.3，
   t=2.1；taker 为负）。SKHY（美线）无信号，与美股名字裁决一致。
4. **经济性裁决：不值得作为独立策略上线。** 0.8 笔/日 × +10 bps（maker、过滤后）×
   可行 clip $20–50k/腿（HL 侧死区 5m 成交额中位 $0.96M、周末仅 $59k）≈ **$2–5/日**；
   且需要双所备付保证金（闭市标记价独立漂移，单腿按 ≥3% 偏离预留）、承担 HL oracle
   事故尾部（SKHX 正是 7/27 −17.9% 事故名字）、依赖 HL growth-mode 费率促销与 BN
   maker 0 费促销、样本仅 20.6 天且 maker 成交按 5m 收盘价假设。列为**观察项**，
   不进试点。

## 1. 回测设计

- 信号：`dev = ln(BN/HL)×1e4 − rolling24h中位数(shift 1)`；|dev| > thr（15/20/30 bps）
  在棒 t 收盘触发，**t+1 收盘价成交**（5m 延迟）；出场 |dev| ≤ 5 bps（同样 t+1 收盘），
  超时 24h；同一时间一对只持一笔。
- 方向：dev>0 → 空 BN / 多 HL；dev<0 → 反向。PnL = side×Δspread（单腿名义 bps 口径）。
- 资金费：持仓期逐事件累计（BN 4h 事件 + HL 每小时），方向正确计入付/收。
- 费用两档：双 taker 9.8 bps（BN 4×2 + HL 0.9×2）；BN maker 0 + HL taker = 1.8 bps。
- 资金费过滤（filtered 组）：入场时刻起 2h 内按已实现事件费率投影，若对持仓方向
  < −3 bps 则放弃入场。实盘中 BN 下一期费率（premium 累计）与 HL 小时费率均实时可见，
  已实现费率是可观察预测值的近似——**这是轻微乐观的假设**。
- KR 时段（UTC）：KRX 00:00–06:30 / KR_AH 06:30–09:00 / KR_DEAD 09:00–23:00 /
  KR_PRE 23:00–24:00 / WKND；8/17（KRX 补休的工作日）单独标 KR_HOL。

## 3. 为什么裸 fade 亏：资金费定价机制

最差一笔（SMSN 7/30 15:00，dev=−30.7 → 多 BN/空 HL，持仓 340 min）：毛利 +15.9 bps
收敛兑现，但横跨 16:00 UTC 一期 BN 资金费 **+50 bps**（多头付）+ 20:00 一期 +7.3，
净 −41.4。BN 便宜 30 bps 不是错价，是市场在给 1 小时后的 50 bps 支付贴现——**dev 信号
与资金费事件在结构上负相关**（fade 方向平均被收 3.7–6.1 bps/笔，约为无条件期望的
8 倍）。任何实现都必须把两所未来资金费投影进入场条件；过滤（2h 投影 < −3 bps 放弃）
把 SKHX taker 均值从 −2.3 抬到 +2.4、maker 从 +5.6 到 +10.4。

## 4. 容量、保证金与尾部

- 成交额（5m 中位，USD）：SKHX BN/HL＝KRX 12.0M/2.9M、KR_DEAD 3.2M/0.96M、
  WKND 0.28M/0.06M；SMSN 约为 SKHX 的 1/8。瓶颈在 HL 腿：死区 $20–50k clip 已占
  HL 5m 成交额 2–5%，周末不可交易。
- 名义收益率：0.8 笔/日 × 10 bps ≈ 8 bps/日（单腿名义）；但双所各备保证金 + 闭市
  标记价独立偏离（周末极值 BN 247 / HL 182 bps，韩股腿是美股 3 倍）要求低杠杆，
  折算到占用资金 ≈ 十几% APR 的量级——在承担 SKHX oracle 事故尾部（7/27 HL 侧
  −17.9%、$57M 清算）的前提下不具吸引力。事故场景对本策略是**双杀**：多 HL 腿被
  坏打印直接清算/ADL，且事故正发生在本策略最活跃的盘前/闭市窗口。
- 促销依赖：maker 口径靠 BN TradFi maker 0 费（2026-03-31 起"直至另行通知"）+
  HL growth-mode taker 0.9 bps（可随时恢复 9 bps → 直接抹掉全部边）。

## 5. 结构性副产品（比策略本身更有用）

1. **Binance 韩股 perp 资金费 4h 一期**（00/04/08/12/16/20 UTC），|rate| p99 22–31
   bps、极值 50 bps/期；美股名字（含 SKHY 美线）8h。`binance_vs_hl.md` B.4 的"8h、
   00/08/16"仅对美股名字成立。对现行 two-pair 策略的含义：SKHYNIX 腿的持仓资金费
   事件密度是假设 8h 的 2 倍，跨 4h 结算点的短持仓要留意单期 30–50 bps 的极端值。
2. **HL xyz 价格可作 Binance 韩股闭市时段的独立参考锚**：两所价差 std 仅 10–17 bps
   且强回归，而 Binance 自家闭市锚是自参照 EWMA。A1（死区被动回归试点）的挂单
   基准若叠加 HL 价格做偏离确认，可过滤掉"两所一起动"（真信息）的假信号——
   这可能比本策略本身更值钱。
3. 三连休期间（8/15–8/17）价差全程安静（KR_HOL 无一次 >20 bps 信号），重开盘前
   （8/18 08:00 KST）出现唯一一次 24 bps episode、56 分钟收敛——与 `events_calendar.md`
   B4"假日 perp 不宜当锚"并行不悖：假日两所彼此一致地漂，错的是共同的锚而非价差。

## 6. 局限

20.6 天、17 笔（主格）；maker 成交按 5m 收盘价假设（未建模排队/逆向选择）；资金费
过滤用已实现费率代理实时可见的预测费率（轻微乐观）；未建模 HL 侧滑点（死区盘口
深度未采样）；事故尾部样本 n=1 且在窗口外（7/27，K 线缓存起点之前）。

## 7. 裁决

**现象真实、机制清楚，但作为独立策略否决**：可提取边只在"资金费过滤 + BN maker +
SKHX + thr≈20"这一格显著（+10 bps/笔、0.8 笔/日、$2–5/日），承担双所尾部与促销
依赖不划算。保留为观察项，两个条件同时满足再复议：(a) HL 韩股腿成交额较当前
放大 ≥5×（clip 可到 $200k+）；(b) A1 试点验证了死区 maker 成交率假设（两者共用
执行层）。副产品 5.1（4h 资金费）与 5.2（HL 锚用于 A1 信号）已可直接使用。
